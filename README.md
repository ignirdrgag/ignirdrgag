## Mon dernier projet

### 🛋️ Salon Mobilier — Gestion de commandes & livraisons

Application **bureautique** (sans navigateur) pour gérer un salon de meubles :
bon de commande PDF, suivi des statuts, livraisons, paiements et rôles utilisateurs.

- JavaFX (interface sidebar sombre + or) · Spring Boot (REST + JWT) · PostgreSQL · OpenPDF
- Authentification par rôle : ADMIN / GÉRANT / VENDEUR
